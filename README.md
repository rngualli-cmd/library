# Terra Enlace

Página de aterrizaje para Terra Enlace, empresa ecuatoriana que cultiva y distribuye café y té de origen dentro del Ecuador.

## Tecnologías

- React 18 + Vite
- Tailwind CSS 3
- Lucide React (iconos)
- Google Fonts: Instrument Serif + Inter

## Desarrollo

```bash
npm install
npm run dev
```

## Compilación

```bash
npm run build
```
